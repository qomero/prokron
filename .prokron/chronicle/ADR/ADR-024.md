# ADR-024: Everything Prokron installs lives in one directory
- Date: 2026-09-22
- Status: ACCEPTED
- Authority: product owner
- Supersedes: none
- Amends: ADR-014, ADR-017, ADR-019
- Corrects: none
- Rejects: a flat `.prokron/` holding authored and generated files together; leaving the runtime and the entry point at the repository root
- Affects: T-LAYOUT-01
- Context: Installing Prokron into an existing repository created five entries at its root — `prokron/`, `.prokron/`, `.prokron-runtime/`, `bin/` and `commands/` — in a project the tool does not own. Four of the five are Prokron's own business: compiled output, runtime code, an entry point and procedure documents. A tool that claims to reduce a project's confusion should not begin by scattering itself across the project's root directory.
- Decision: Everything Prokron installs goes under a single `.prokron/` directory: `chronicle/` for the authored records, `compiled/` for generated state, `runtime/` for the Python modules, `commands/` for the procedure documents, and `prokron` as the entry point. The only paths that remain outside it are the ones a host reads by a fixed address and Prokron cannot choose — `AGENTS.md`, `CLAUDE.md`, `.claude/commands/`, `.opencode/commands/` and `.agents/skills/prokron/`.
- Consequences: The separation ADR-014 established between authored authority and compiled output is unchanged; it becomes `chronicle/` against `compiled/` rather than two root directories, and the compiler still writes only into `compiled/`. A dot directory is hidden by default in a file browser, and the chronicle is written to be read by people — accepted, because the reading surfaces are `status`, the dashboard and the files themselves, all of which are reached by path or by command rather than by browsing. Every v0.2 installation must be relocated, so `prokron migrate` now handles a v0.2 layout as well as a v0.1 one. That relocation archives nothing, which narrows ADR-019: the archive exists to protect records from being rewritten, and a move rewrites nothing. Archiving a whole chronicle to guard against a transformation that does not happen would be ceremony, not safety. Paths recorded in existing ADRs, tasks and journal entries are left as written: they were accurate when written, and rewriting them would falsify the record.
