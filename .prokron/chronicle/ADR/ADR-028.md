# ADR-028: The continuity pilot was completed rather than deferred
- Date: 2026-09-22
- Status: ACCEPTED
- Authority: product owner
- Supersedes: none
- Amends: ADR-020
- Corrects: none
- Rejects: closing Gate P1-CONTINUITY on partial evidence; carrying the pilot into the Phase 3 exit audit now that it has been run
- Affects: T-PILOT-01
- Context: ADR-020 closed Phase 2 with the continuity pilot unfinished at step 3 of 7, parked the remainder as named debt, and set the payoff at the Phase 3 exit audit. That deferral was made when running the remaining steps looked expensive. It was not: the five outstanding steps took one session. The deferral also carried a risk ADR-020 stated plainly — that Phase 3 would be built on a workflow whose cross-session agent compliance was unverified — and that risk is now removed before Phase 3 opens rather than after.
- Decision: The pilot was run in full against v0.4.0 and recorded in `docs/pilot-2026-09-22.md`. All seven criteria pass. The earlier partial run is superseded rather than reused: it was measured against v0.2.1 and its evidence cites an entry point and a directory that no longer exist, so it describes a product that is not shipping. Gate P1-CONTINUITY is GREEN on complete, current evidence, and P1 is COMPLETE. The debt ADR-020 carried is paid here, not at the Phase 3 exit audit.
- Consequences: Every phase on record is now COMPLETE and every gate is green, so the repository no longer demonstrates its own honesty by pointing at a red gate. The public documentation said exactly that and has been corrected; the dashboard figures it shows were regenerated. Two claims remain unproven and are still stated as unproven: behaviour against a real host limit was never observed, because no host exposed one to watch, and nothing was simulated in its place; and step 7 passed on the owner's attestation without a point-by-point account or a comparison against an agent's reading of the same chronicle. The Phase 3 exit audit keeps the pilot as a procedure to re-run against a larger build, but no longer owes it as debt.
