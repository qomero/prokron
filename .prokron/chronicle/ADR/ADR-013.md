# ADR-013: Adopt the Phase 2 specification and reinstate a deterministic runtime
- Date: 2026-09-21
- Status: ACCEPTED
- Authority: product owner; docs/Phase 2.md
- Supersedes: ADR-008
- Amends: ADR-001
- Corrects: none
- Rejects: agent-computed project state as authority
- Affects: T-P2-PLAN-01, T-P2-01, T-P2-06
- Context: ADR-008 reduced Prokron to Markdown records plus agent instructions and removed the application runtime. Phase 2 requires task status, phase status, dependency resolution, acceptance state, gate state, ready work, blockers, critical path, progress metrics, Gantt source data, and dashboard rendering to be produced without an LLM. A convention of instructions cannot guarantee that; the same inputs would compile differently per model.
- Decision: docs/Phase 2.md governs where it conflicts with earlier decisions. Prokron regains a deterministic compiler and CLI (validate, compile, status, graph, dashboard, explain, context). Authored Markdown remains the only source of truth; the runtime may read authority and write derived state, and may never modify authority. LLMs explain, summarize, audit, and implement; they never become a hidden source of project state.
- Consequences: The workflow-only product framing ends. Release, packaging, and regression burden returns. The chronicle workflow, entry modes, and preservation rules from ADR-009 through ADR-012 remain in force except where ADR-014 and ADR-015 amend them.
