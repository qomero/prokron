# ADR-039: Propose changes from a cambos-td fork
- Date: 2026-09-23
- Status: ACCEPTED
- Authority: product owner
- Supersedes: none
- Amends: ADR-033, ADR-034
- Corrects: none
- Rejects: changing `origin`; pushing to `qomero/prokron` without write access
- Affects: T-BASELINE-01
- Context: Pushing `cambos-td/baseline` to `origin` was refused with HTTP 403: `cambos-td` has read-only access to `qomero/prokron`. ADR-033 left moving a remote to an explicitly named target, and the owner named a fork under `cambos-td`.
- Decision: Fork `qomero/prokron` to `cambos-td/prokron`, add it as the remote `fork`, push review branches there, and open pull requests from the fork against `qomero/prokron:main`. `origin` stays unchanged.
- Consequences: Review follows the ordinary fork workflow and needs no write access to the upstream repository. The fork is public because the upstream is public. A maintainer of `qomero/prokron` merges.
