# Decisions

Accepted engineering decision authority. One file per ADR, append-only.
A decision that changes is superseded by a new ADR; the earlier file stays.

A decision recorded after the fact, by `/prokron-baseline`, carries
`Origin: RECONSTRUCTED` and an `Evidence:` field naming what it was inferred
from. It starts `PROPOSED` and becomes `ACCEPTED` only when a person confirms
it and is named in `Authority`.
