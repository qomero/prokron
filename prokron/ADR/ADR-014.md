# ADR-014: Separate authored authority from compiled state
- Date: 2026-09-21
- Status: ACCEPTED
- Authority: docs/Phase 2.md sections 3, 10, 19, 29
- Supersedes: none
- Amends: ADR-001, ADR-009, ADR-011, ADR-013
- Corrects: none
- Rejects: none
- Affects: T-P2-01, T-P2-07
- Context: Phase 2 states that everything under `.prokron/` is generated and that `rm -rf .prokron && prokron compile` must reproduce the same logical state, while also naming TASKS.md, PHASES.md, ACCEPTANCE.md, ADR/, INTENT.md, and HANDOFF.md as authority. Both cannot hold while authority lives in `.prokron/`.
- Decision: Authored authority moves to a visible `prokron/` directory at the repository root. `.prokron/` becomes compiled output only: project.json, dashboard.html, and Mermaid artifacts. Humans and agents edit `prokron/`; only the compiler writes `.prokron/`. Deleting `.prokron/` loses nothing.
- Consequences: Every installed path, adapter, command prompt, template, and README reference changes once, under T-P2-01. `.prokron/` becomes safe to ignore in Git. The directory pair reads as authored versus compiled, which is the distinction Phase 2 depends on.
