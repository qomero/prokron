# ADR-016: Implement the Phase 2 compiler with the Python standard library only
- Date: 2026-09-21
- Status: ACCEPTED
- Authority: implementation choice under ADR-013
- Supersedes: none
- Amends: ADR-013
- Corrects: none
- Rejects: none
- Affects: T-P2-06, T-P2-07, T-P2-10, T-P2-11
- Context: The runtime must stay local-first, offline-capable, model-agnostic, and trivial to install beside a shell bootstrap. Phase 2 also forbids a backend, a database, and a frontend framework for the dashboard.
- Decision: Implement the compiler, validator, analytics, renderers, and CLI as typed Python using the standard library only, with no third-party runtime dependency. The dashboard ships as static HTML, CSS, and JavaScript reading project.json, with Mermaid loaded as a vendored or CDN asset and no build step.
- Consequences: Parsing, graph analysis, and rendering are written rather than imported. Installation stays a file copy plus a Python interpreter. Development tooling such as linters and type checkers is allowed; runtime dependencies are not.
