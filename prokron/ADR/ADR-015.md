# ADR-015: Adopt the Phase 2 execution document set
- Date: 2026-09-21
- Status: ACCEPTED
- Authority: docs/Phase 2.md sections 3.2, 4, 7, 8
- Supersedes: none
- Amends: ADR-001, ADR-012, ADR-014
- Corrects: none
- Rejects: none
- Affects: T-P2-01, T-P2-02, T-P2-03, T-P2-05
- Context: Phase 2 names PHASES.md, TASKS.md, ACCEPTANCE.md, ADR/, INTENT.md, and HANDOFF.md as execution authority. The chronicle currently uses TASKS.md, DECISIONS.md, INTENT.md, JOURNAL.md, STATE.md, and TASK_GRAPH.md.
- Decision: Authority becomes PHASES.md, TASKS.md, ACCEPTANCE.md, ADR/, INTENT.md, and HANDOFF.md under `prokron/`. DECISIONS.md splits into one file per ADR inside `prokron/ADR/`, preserving identifiers and content. HANDOFF.md holds current implementation continuity; JOURNAL.md remains append-only history and holds no authority. STATE.md and TASK_GRAPH.md stop being hand-maintained views and become compiled artifacts under `.prokron/`.
- Consequences: The six-file chronicle becomes an eight-document authority set plus compiled views. Read order, templates, workflows, and the installed guide are rewritten once. No project fact gains a second source of truth.
